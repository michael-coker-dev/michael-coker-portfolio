THE BRIEF

Making financial information easier to scan

The concept explores a banking dashboard where a user can quickly understand an account summary and find common areas such as deposits, transfers, cards, statements and support. The emphasis is on readable information hierarchy and a consistent experience across multiple screens.

WHAT I BUILT

Interface areas

  • Landing page and account entry screens
  • Dashboard with account summary layout
  • Deposit and transfer workflow screens
  • Card, statement and support page concepts
  • Responsive layouts and reusable visual patterns

Design and implementation focus

A calm green-and-white visual direction, clear page hierarchy and familiar dashboard patterns designed to keep key information easy to locate.

Firebase integration points are present in the prototype, but the live Firebase security rules and backend configuration have not been independently verified.

TECHNICAL SCOPE

Tools and structure

Built with HTML, CSS and JavaScript, with Firebase Authentication and Firestore integration points. The project is organised as a collection of static pages for the main app areas.

WHAT I LEARNED

Handling sensitive workflows responsibly

Reviewing the prototype highlighted why financial actions must be enforced by trusted backend logic rather than browser-only code. Deposit and transfer UI handlers have been disabled in this demo.

Prototype disclaimer: Fund Grow is not a bank, payment processor or investment service. Balances and interface data are illustrative. Deposit and transfer actions are disabled; no real money is accepted or moved. Do not enter real personal or financial information.
