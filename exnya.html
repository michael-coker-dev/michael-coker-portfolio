THE BRIEF

Bringing several exchange workflows into one interface

The goal was to build a cohesive front-end concept for a cryptocurrency exchange, with a clear landing experience and connected screens for markets, swaps, wallets, peer-to-peer trading and account settings. The work focuses on interface structure, visual consistency and navigation across multiple pages.

WHAT I BUILT

Core interface areas

  • Public landing and account entry screens
  • Market listings and trading-oriented dashboard views
  • Wallet, swap and peer-to-peer interface screens
  • Profile, settings and security page concepts
  • Shared styling with dark and light theme support

Design and implementation focus

Consistent page layouts, reusable front-end helpers, responsive styling and clear visual hierarchy across a multi-page experience.

The repository also contains Supabase migration and Edge Function source examples. Their presence in the repository does not confirm that a live backend is deployed or secure.

TECHNICAL SCOPE

Tools and structure

Built with HTML, CSS and vanilla JavaScript, with Supabase integration points for authentication and data-backed screens. The repository includes SQL migration source and an Edge Function example.

WHAT I LEARNED

Designing beyond a single page

This project helped me think about how navigation, account states and repeated interface patterns work together across a larger application rather than treating every screen as an isolated design.

Prototype disclaimer: EXNYA is not a live exchange, broker, custodian or investment service. It has no verified production users or processed transactions. Swap pricing and P2P escrow are not production-safe; do not deposit funds or submit identity documents. See the repository's SECURITY.md for known limitations.
